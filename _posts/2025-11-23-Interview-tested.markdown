## 1. 概率论基础

**题干：** 在现代概率论中，随机变量的本质是什么？

- A. 定义在概率空间上的可测函数
- B. 未知数值的变量
- C. 描述频率的统计量
- D. 计算期望的工具

**正确答案：A**

**深度解析：**

- **概念剖析**：初等概率论中把随机变量理解为“随试验结果变化的量”，但这不够严谨。现代概率论基于测度论，定义随机变量 X 是一个从样本空间 Ω 到实数集 R 的可测函数 `X: Ω → R`。
- **为什么是“可测”**：为了保证形如 `{X ≤ x}` 这样的集合能够被赋予概率测度，必须要求原像可测。
- **逐项排除**：B 是通俗但不严格的描述；C 描述的是“概率”的频率学派解释；D 是随机变量的应用（计算期望），并非其数学本质。
- **知识点来源**：概率论与数理统计（测度论基础）。

## 2. 随机过程

**题干：** 对于一个随机过程，自相关系数（归一化的自相关函数）的取值范围是：

- A. [0, 1]
- B. [-1, 1]
- C. [0, +∞)
- D. (-∞, +∞)

**正确答案：B**

**深度解析：**

- **公式推导**：归一化自相关函数定义 `ρ(τ) = (R(τ) - μ²) / σ²`，或零均值下 `ρ(τ) = R(τ) / R(0)`。
- **柯西-施瓦茨不等式**：对于任意随机变量 X, Y，有 `|E[XY]| ≤ √(E[X²] E[Y²])`。令 `X = X(t)`，`Y = X(t+τ)`，代入得 `|R(τ)| ≤ R(0)`，即 `|ρ(τ)| ≤ 1`。
- **物理意义**：相关系数衡量的是两个时间点取值的相似程度（正相关、负相关、不相关），其值必然在 -1 到 1 之间。原始自相关函数 R(τ) 随信号功率变化可趋于无穷，但归一化后就被约束在 [-1, 1]。
- **知识点来源**：随机过程、信号与系统。

**背景知识：**

- **描述工具链**：随机过程 $X(t)$ 是随时间索引的一族随机变量，刻画其二阶统计特性依赖三个函数：自相关函数 $R(\tau) = E[X(t)X(t+\tau)]$（宽平稳时只依赖时间差 $\tau$）、自协方差函数 $C(\tau) = R(\tau) - \mu^2$、自相关系数 $\rho(\tau) = C(\tau)/\sigma^2$。
- **归一化的意义**：$|\rho(\tau)| \le 1$ 是柯西–施瓦茨不等式 $|E[XY]| \le \sqrt{E[X^2]\,E[Y^2]}$ 的直接推论。取 $X = X(t)$、$Y = X(t+\tau)$ 得 $|R(\tau)| \le R(0)$。归一化后与量纲、信号功率无关，便于跨信号比较。
- **边界值含义**：$\rho = 1$ 完全正相关；$\rho = -1$ 完全负相关（如正弦信号相隔半周期）；$\rho = 0$ 线性不相关。
- **选项辨析**：A 忽略了负相关情形；C 对应未归一化的功率信号 $R(\tau)$——非负但可无界，恰好说明归一化的必要性；D 无统计意义。任何“相关系数”（自相关、互相关、Pearson）都被约束在 $[-1, 1]$。
- **延伸**：Wiener–Khinchin 定理指出宽平稳过程的自相关函数与功率谱密度构成傅里叶变换对，是噪声建模与 ARMA 模型分析的基础。

## 3. 机器学习基础

**题干：** 关于半监督学习和强化学习的描述，正确的是

- A. 强化学习利用奖励信号
- B. 强化学习无需数据
- C. 半监督需与环境交互
- D. 半监督只能用有标签数据

**正确答案：A**

**深度解析：**

- **范式对比**：监督学习（全标签）、无监督学习（无标签）、半监督学习（少量标签 + 大量无标签，静态数据）、强化学习（智能体与环境动态交互）。
- **逐项排除**：B 错在强化学习需要与环境交互产生的序列数据（状态、动作、奖励），虽然强调探索，但不是“完全随机”；C 混淆概念，与环境交互拿奖励是 RL 的专属特征；D 严重错误，半监督学习的核心就在于“利用大量无标签数据”提升泛化能力。
- **知识点来源**：机器学习基础范式。

**背景知识：**

- **四大范式对比**：

| 范式 | 数据形态 | 典型任务 |
|---|---|---|
| 监督学习 | $(x, y)$ 全标签 | 分类、回归 |
| 无监督学习 | 只有 $x$ | 聚类、降维、密度估计 |
| 半监督学习 | 少量标签 + 大量无标签 | 利用无标签结构提升泛化 |
| 强化学习 | 交互产生的 $(s, a, r, s')$ 序列 | 博弈、控制、RLHF |

- **选项 A ✓**：奖励是 RL 的定义性特征。RL 建模为马尔可夫决策过程（MDP）四元组 $(S, A, P, R)$，目标是最大化累计折扣回报 $\sum_t \gamma^t r_t$。
- **选项 B**：RL 并非无需数据，而是数据由在线交互产生——序列高度相关、非 i.i.d.，这正是 RL 样本效率低的根源。
- **选项 C**：与动态环境交互是 RL 专属；半监督处理静态数据集，依赖三大假设：平滑性、聚类、流形。
- **选项 D**：半监督的核心恰是利用无标签数据，代表方法：自训练（伪标签）、协同训练、一致性正则。
- **易混概念**：自监督学习从数据自身构造监督信号（如掩码语言模型 MLM）；主动学习由模型挑选最有价值的样本请求标注。

## 4. 大模型量化

**题干：** 在端侧大模型中，采用 INT4 量化的主要直接收益是什么？

- A. 完全避免冷启动
- B. 降低权重存储与运行内存占用
- C. 消除 KV Cache 开销
- D. 一定提升模型精度

**正确答案：B**

**深度解析：**

- **量化本质**：将高精度浮点数（如 FP16 占 2 字节）映射为低比特整数（如 INT4 占 0.5 字节），模型体积压缩至原来的 1/4，直接降低了硬盘存储和加载后的内存（显存）占用。这是端侧部署的基石。
- **逐项排除**：A 错，量化能加速模型加载，缓解冷启动，但不能“完全避免”；C 错，KV Cache 是在推理时生成的，量化权重不直接消除 KV Cache（除非专门做 KV Cache 量化）；D 错，量化是有损压缩，通常伴随精度下降，旨在平衡性能与效率。
- **知识点来源**：大模型部署与推理优化。

**背景知识：**

- **量化原理**：将浮点权重映射为低比特整数，由 scale 与 zero-point 参数化：$w_{int} \approx \mathrm{round}(w/s) + z$。INT4 每参数仅 0.5 Byte。
- **精度-显存对照**：

| 精度 | 字节/参数 | 7B 权重 |
|---|---|---|
| FP32 | 4 | 28 GB |
| FP16/BF16 | 2 | 14 GB |
| INT8 | 1 | 7 GB |
| INT4 | 0.5 | 3.5 GB |

- **选项辨析**：A 冷启动还包括进程初始化、kernel 编译等环节，量化只能加速权重加载；C KV Cache 属于推理时的激活状态，需专门的 KV Cache 量化才能压缩；D 量化是有损压缩，低比特通常掉点，weight-only 方法（GPTQ/AWQ）靠校准恢复精度而非“一定提升”。
- **附带收益**：权重变小后显存带宽压力降低，decode 阶段（带宽受限）直接提速。

## 5. RAG（检索增强生成）

**题干：** 上线后发现“答非所问”增加。排查发现：检索召回 Top5 中常有 3 条语义相关性低文本。你应先做：

- A. 加 rerank 模型
- B. 增加 max_new_tokens
- C. chunk 大小翻倍，取消 overlap
- D. 温度从 0.2 改 0.9

**正确答案：A**

**深度解析：**

- **问题定位**：RAG 的“检索（Retrieval）”环节污染了上下文，大模型基于错误上下文生成，自然“答非所问”。
- **解决方案**：初步召回通常基于向量余弦相似度，只能保证“大致相关”。Rerank（重排）模型采用交叉编码器（Cross-Encoder），能对 Query 和每个文档进行更深度的语义交互打分，将真正相关的内容排在前面，并过滤掉噪声。
- **排他分析**：B `max_new_tokens` 只加长输出、不改上下文质量；C 无 overlap 的分块会在边界截断语义，反而伤害召回；D 温度从 0.2 升到 0.9 放大采样随机性，加剧幻觉。
- **知识点来源**：大模型应用开发、RAG 技术栈。

**背景知识：**

- **RAG 流水线**：分块（chunking）→ 嵌入（embedding）→ 向量召回 → 可选重排（rerank）→ 拼接上下文 → 生成。
- **双编码器 vs 交叉编码器**：召回阶段的 bi-encoder 将 query 与文档独立编码为向量再算余弦相似度——可离线建索引、速度快，但只能保证“大致相关”；rerank 的 cross-encoder 将 (query, doc) 拼接后共同过注意力逐对深交互打分——精度高但每个候选都要一次前向，只能用于粗排后的小候选集（如 top-100 → top-5）。这是“召回求快、精排求准”的经典漏斗架构。
- **上下文污染**：噪声文档会诱导模型基于错误证据生成（garbage in, garbage out）；LLM 还存在 "lost in the middle" 现象——对上下文中部信息的利用率低。
- **选项辨析**：B `max_new_tokens` 只加长输出、不改上下文质量；C 无 overlap 的分块会在边界截断语义，反而伤害召回；D 温度从 0.2 升到 0.9 放大采样随机性，加剧幻觉。

## 6. 线性代数

**题干：** 在矩阵 `A = UΣV^T` 的分解中，关于矩阵 U 和 V 的性质，下列说法正确的是：

- A. 元素全为正
- B. U 和 V 均为正交矩阵
- C. U 上三角 V 下三角
- D. U 和 V 均为对角矩阵

**正确答案：B**

**深度解析：**

- **SVD 定义**：奇异值分解 `A = UΣV^T`。U 是 m×m 的正交矩阵（左奇异向量），V 是 n×n 的正交矩阵（右奇异向量）。Σ 是对角矩阵（奇异值）。
- **正交性**：正交矩阵满足 `U^T U = UU^T = I`，其列向量是单位正交基。允许元素为负数。
- **排他分析**：C 是 QR 分解或 LU 分解的特征；D 是对 Σ 的描述。SVD 的核心就是通过两个正交基的旋转加上中间的缩放，实现对任意矩阵的分解。
- **知识点来源**：线性代数（SVD 分解）。

**背景知识：**

- **SVD 定义**：任意 $m \times n$ 实矩阵都存在分解 $A = U\Sigma V^\top$：$U$ 的列是 $AA^\top$ 的特征向量（左奇异向量，$m \times m$ 正交阵）；$V$ 的列是 $A^\top A$ 的特征向量（右奇异向量，$n \times n$ 正交阵）；$\Sigma$ 对角非负降序（奇异值）。
- **几何意义**：任何线性映射 = 旋转（$V^\top$）→ 各轴缩放（$\Sigma$）→ 旋转（$U$）。正交矩阵满足 $Q^\top Q = I$，列是单位正交基，代表保范数变换，元素可正可负。
- **矩阵分解对比**：

| 分解 | 形式 | 关键性质 |
|---|---|---|
| SVD | $A = U\Sigma V^\top$ | 任意矩阵存在，$U, V$ 正交 |
| 特征分解 | $A = P\Lambda P^{-1}$ | 仅适用于可对角化方阵 |
| QR | $A = QR$ | $Q$ 正交、$R$ 上三角 |
| LU | $A = LU$ | 下三角 × 上三角 |

- **应用**：最优低秩逼近（Eckart–Young 定理）、伪逆 $A^+ = V\Sigma^+ U^\top$、PCA、推荐系统隐因子、图像压缩。
- **选项辨析**：A 正交性与符号无关（置换矩阵、旋转矩阵均含负元素）；C 三角是 QR/LU 的特征；D 对角是 $\Sigma$ 的性质。

## 7. 数据分析与统计

**题干：** 算法 X 的 5 组数据为 `[(12.5, 8.2), (13.2, 9.0), (11.8, 7.5), (12.0, 8.0), (12.5, 8.3)]`；算法 Y 为 `[(14.0, 10.5), (13.5, 9.8), (15.2, 11.2), (14.8, 10.8), (14.5, 10.0)]`。求 X 的路径长度均值与 Y 的耗时极差。

- A. 12.5, 1.7
- B. 12.4, 1.4
- C. 12.5, 1.4
- D. 12.4, 1.7

**正确答案：B**

**深度解析：**

- **均值计算（X）**：只取第一个维度的数据。`(12.5 + 13.2 + 11.8 + 12.0 + 12.5) / 5 = 62.0 / 5 = 12.4 m`。
- **极差计算（Y）**：只取第二个维度（耗时）的数据。集合为 `{10.5, 9.8, 11.2, 10.8, 10.0}`。最大值 = 11.2，最小值 = 9.8。极差 = 最大值 - 最小值 = 1.4 s。
- **避坑指南**：极差（Range）仅受最大值和最小值影响，其他中间数据均不影响计算结果。
- **知识点来源**：概率论与数理统计（描述性统计）。

## 8. 大模型推理

**题干：** 生成式大模型推理中，Prefill 阶段的核心作用是（）

- A. 一次性处理输入 prompt 的所有 Token，计算并缓存 KVCache
- B. 逐 token 生成
- C. 压缩模型
- D. 评估准确率

**正确答案：A**

**深度解析：**

- **两阶段推理机制**：大模型推理分为 Prefill（预填充）和 Decode（解码）。
- **Prefill**：并行处理用户输入的整个 Prompt，一次性计算出所有 Token 的 Key 和 Value，存入显存（KVCache）。此阶段是计算密集型（Compute-bound），决定了首字延迟（TTFT）。
- **Decode**：自回归逐个生成 Token，每次只计算新 Token 的 K 和 V，并复用之前的 KVCache。此阶段是显存带宽密集型（Memory-bound）。
- **排他分析**：B 描述的是 Decode 阶段。C 属于模型优化技术，不是推理阶段的功能。D 属于训练/评估阶段。
- **知识点来源**：大语言模型推理（Prefill 与 Decode）。

**背景知识：**

- **两阶段特性对比**：

| 阶段 | 计算方式 | 瓶颈 | 决定指标 |
|---|---|---|---|
| Prefill | 整个 prompt 并行处理，算出全部 K/V 写入 KV Cache | 大 GEMM，算术强度高 → 计算密集（compute-bound） | TTFT 首字延迟 |
| Decode | 每步 1 个新 token，追加 K/V 并读全部历史 Cache | GEMV 小算子、反复读权重与 Cache → 带宽密集（memory-bound） | TPOT token 间延迟 |

- **KV Cache 显存公式**：$2 \times L \times n_{heads} \times d_{head} \times seq \times batch \times bytes$（2 对应 K 与 V），随上下文长度线性增长——这是长上下文昂贵、以及 GQA/MQA、PagedAttention（vLLM）、continuous batching 等优化出现的原因。
- **选项辨析**：B 是 Decode 阶段；C 量化/蒸馏/剪枝是模型优化技术而非推理阶段的职能；D 属于离线评测环节。

## 9. 线性代数

**题干：** 矩阵乘法中，`A ∈ R^{m×n}` 与 `B ∈ R^{n×p}` 的乘积维度是？

- A. n×n
- B. p×m
- C. m×n
- D. m×p

**正确答案：D**

**深度解析：**

- **矩阵乘法法则**：`(m×n) · (n×p) = (m×p)`。中间的 n 必须相等才能相乘并互相抵消。
- **速记口诀**：“中间消掉，两边提取”。第一个矩阵的行数 m 和第二个矩阵的列数 p 构成结果矩阵的维度。
- **知识点来源**：线性代数（矩阵运算）。

## 10. 特征工程

**题干：** 特征工程中主成分分析（PCA）的主要作用是什么

- A. 特征降维
- B. 特征转换
- C. 特征构造
- D. 特征编码

**正确答案：A**

**深度解析：**

- **PCA 原理**：通过正交变换，将一组可能存在线性相关的变量转换为一组线性不相关的新变量（主成分）。通过保留方差最大的前 k 个主成分，丢弃方差小的成分，实现降维。
- **核心目的**：解决“维度灾难”，减少计算量，缓解过拟合，并用于数据可视化。
- **排他分析**：B“特征转换”太泛（标准化、归一化也是转换）；C“特征构造”强调从业务出发创造新特征；D“特征编码”针对类别型变量（如 One-Hot）。PCA 特指线性降维技术。
- **知识点来源**：机器学习（特征工程、PCA）。

**背景知识：**

- **PCA 原理**：数据中心化后求协方差矩阵，特征分解 $\Sigma = W\Lambda W^\top$，取特征值（方差）最大的前 $k$ 个正交方向投影 $Z = XW_k$，等价于对中心化数据矩阵做 SVD。保留方差比例 = 前 $k$ 个特征值之和 / 全部特征值之和。
- **降维动机**：缓解维度灾难（高维下距离度量失效）、去噪（小方差成分常含噪声）、可视化、消除共线性、加速训练。
- **特征工程四类辨析**：

| 类别 | 定义 | 例子 |
|---|---|---|
| 降维 | 压缩特征数量 | PCA、LDA、t-SNE |
| 转换 | 改变取值尺度/分布 | 标准化、归一化、log 变换 |
| 构造 | 从业务出发创造新特征 | BMI = 体重/身高² |
| 编码 | 类别变量数值化 | One-Hot、Target Encoding、Embedding |

- **选项辨析**：B “转换”是上位概念（标准化也是转换）；C 构造强调业务新特征；D 编码针对类别变量。
- **局限**：仅捕获线性关系（非线性用 Kernel PCA / t-SNE / UMAP）、主成分失去可解释性、方差大 ≠ 判别信息多（对比监督的 LDA）、对量纲敏感必须先标准化。

## 11. Transformer 架构

**题干：** 在 Transformer 模型的多头注意力机制中，多个注意力头的输出最终是如何处理的？

- A. 取平均值
- B. 随机选一个
- C. 按位相加后归一化
- D. 拼接后通过线性变换

**正确答案：D**

**深度解析：**

- **标准公式**：`MultiHead(Q, K, V) = Concat(head_1, …, head_h) W^O`。
- **步骤拆解**：每个头在各自子空间独立计算得到输出向量。所有头的输出首先沿着特征维度拼接（Concat），恢复回模型原始维度 d_model，然后乘上输出权重矩阵 `W^O` 进行线性变换，实现跨头的信息融合。
- **排他分析**：A 会混淆不同子空间的信息；B 直接丢弃信息；C 违反原论文设计。
- **知识点来源**：深度学习（Transformer 架构）。

**背景知识：**

- **完整流程**：每个头 $\mathrm{head}_i = \mathrm{Attention}(QW_i^Q, KW_i^K, VW_i^V)$，维度 `d_k = d_model / h`；各头并行计算后沿特征维拼接（Concat）回 `d_model`，再乘 $W^O \in \mathbb{R}^{d_{model} \times d_{model}}$ 线性融合。
- **关键理解**：拼接本身不做信息融合，融合由可学习的 $W^O$ 完成——让模型自己学“各头如何混合”。
- **为什么多头**：不同头关注不同类型的关系（句法、共指、位置等），相当于注意力的集成。
- **选项辨析**：A 取平均强加“各头等权”假设，剥夺模型学习融合权重的能力；B 随机选头丢弃 $h-1$ 个头的信息且训练不稳定；C 按位相加是固定权重的融合，相当于把 $W^O$ 退化为常数矩阵，违反原论文设计。
- **变体**：MQA 所有 Q 头共享一个 KV 头（最省 KV Cache）；GQA 分组共享（精度与开销折中）；交叉注意力用于 encoder-decoder。

## 12. 大模型量化（QAT）

**题干：** QAT（量化感知训练）的主要缺点是：

- A. 精度不如 PTQ
- B. 无法在 GPU 运行
- C. 需要极高计算资源
- D. 增加模型体积

**正确答案：C**

**深度解析：**

- **概念对比**：
  - **PTQ（训练后量化）**：模型训练完后，用少量校准数据跑前向传播计算量化参数。省时省力，但极低比特（如 4bit）下精度损失大。
  - **QAT（量化感知训练）**：在训练/微调阶段插入伪量化节点（模拟量化误差），让模型在训练中“适应”低精度。
- **缺点**：QAT 需要进行完整的反向传播和参数更新，且需要大量训练数据，因此需要极高的计算资源和时间成本。
- **排他分析**：QAT 精度通常高于 PTQ（A 错）；PTQ 和 QAT 都能在 GPU 上运行（B 错）；量化必定减小体积（D 错）。
- **知识点来源**：大模型量化技术。

**背景知识：**

- **PTQ vs QAT 对比**：

| | PTQ 训练后量化 | QAT 量化感知训练 |
|---|---|---|
| 时机 | 训练完成后 | 训练/微调过程中 |
| 数据 | 少量校准数据（如 128 条） | 大量训练数据 |
| 原理 | 统计激活范围定 scale（min/max、percentile、KL 校准） | 插入伪量化节点，前向模拟量化误差 |
| 成本 | 分钟级、零训练 | 完整反向传播、高算力（即选项 C） |
| 精度 | 极低比特（≤4bit）损失明显 | 极低比特下最好 |

- **关键技术**：QAT 中 round 操作不可导，用直通估计器（STE）让梯度直接穿过；PTQ 的代表方法有 GPTQ（基于 Hessian 的逐层误差补偿）、AWQ（激活感知）、LLM.int8（离群值分离）。
- **选项辨析**：A 说反——QAT 精度通常更高，代价正是资源；B 两者都能在 GPU 上运行；D 量化按定义减小体积，QAT 只是训练手段。

## 13. 显存估算

**题干：** 如果一个 7B 模型使用 INT4 量化，其权重占用的显存空间大约是：

- A. 3.5 GB
- B. 7 GB
- C. 14 GB
- D. 28 GB

**正确答案：A**

**深度解析：**

- **基础换算**：1 Byte = 8 bit。INT4 表示每个参数占用 4 bit，即 0.5 Byte。
- **计算过程**：7B 模型 = `7 × 10^9` 个参数。所需空间 = `7 × 10^9 × 0.5 Byte = 3.5 × 10^9 Byte ≈ 3.5 GB`。
- **延伸记忆**：FP16/BF16（2 Byte）为 14 GB；FP32（4 Byte）为 28 GB；INT8（1 Byte）为 7 GB。
- **知识点来源**：大模型推理与显存计算。

**背景知识：**

- **估算公式**：显存 = 参数量 × 每参数字节数。$7 \times 10^9 \times 0.5\ \mathrm{Byte} = 3.5\ \mathrm{GB}$。其余选项分别对应 INT8（7 GB）、FP16（14 GB）、FP32（28 GB），是命题人设置的换算陷阱。
- **完整显存构成**：总显存 = 权重 + KV Cache（随上下文线性增长）+ 激活值 + 框架开销。仅估权重会低估实际占用。
- **精度补充**：BF16 与 FP16 同为 2 字节，但指数位更宽、动态范围更大，无需 loss scaling，是大模型训练/推理的默认精度。

## 14. Transformer 架构

**题干：** 在 Transformer 的自注意力机制中，Scaled Dot-Product Attention 公式中的缩放因子是什么？为什么需要缩放？

- A. 除以 h，减少计算量
- B. 除以 d_k，归一化
- C. 除以 d_v，平衡
- D. 除以 √d_k，防止内积过大导致 softmax 梯度饱和

**正确答案：D**

**深度解析：**

- **数学推导**：假设 Q 和 K 的元素均服从均值 0、方差 1 的独立分布，则点积 `Q·K^T = Σ q_i k_i` 的方差为 `d_k`。当 `d_k` 很大时（如 64、512），点积结果方差极大。
- **梯度饱和问题**：Softmax 函数在输入极大或极小时，梯度趋近于 0（即梯度消失/饱和），导致训练停滞。
- **缩放因子**：除以 `√(d_k)` 可以将方差拉回到 1，使 Softmax 输入保持在合理范围，维持梯度的稳定流动。
- **排他分析**：A 与头数无关；B 错在除以 `d_k` 过度缩放；C 与 `d_v` 无关。
- **知识点来源**：深度学习（Transformer）。

**背景知识：**

- **公式**：$\mathrm{Attention}(Q, K, V) = \mathrm{softmax}\left(\dfrac{QK^\top}{\sqrt{d_k}}\right)V$。
- **方差推导**：设 $q_i, k_i$ 独立同分布、均值 0 方差 1，则点积 $q \cdot k = \sum_{i=1}^{d_k} q_i k_i$ 的方差为 $d_k$（标准差 $\sqrt{d_k}$）。`d_k = 64` 时标准差已达 8，logit 数值巨大。
- **饱和后果**：softmax 对巨大输入会饱和——最大项概率趋于 1、其余趋于 0，此时梯度 $p_i(1-p_i) \to 0$，梯度消失、训练停滞。除以 $\sqrt{d_k}$ 把方差拉回 1，softmax 保持“软”分布，梯度顺畅流动。
- **选项辨析**：A 头数 $h$ 根本不出现在注意力公式中；B 除以 $d_k$ 使方差变为 $1/d_k$，softmax 输出趋于均匀分布，注意力失去选择性（过度缩放）；C logit 由 `d_k` 决定，与输出维度 `d_v` 无关。
- **对比**：加性注意力（Bahdanau）用前馈网络打分，天然无需缩放，但无法高效矩阵化，现代架构几乎全用缩放点积。

**题干：** 在浮点数系统中，机器精度 eps 的定义最接近的是：

- A. 满足 `1 + eps > 1` 的最小正数
- B. 满足 `eps² ≈ 0`
- C. 最小可表示正数
- D. 最大可表示正数

## 16. 深度学习（多选）

**题干：** 关于 Softmax 实现中减去最大值的技巧，以下正确的是：

- A. 保证数值稳定，梯度不变
- B. 改变梯度计算，需特殊处理
- C. 利用指数齐次性，数学等价，防溢出
- D. 改变数学定义

**正确答案：A、C**

**深度解析：**

- **数学等价性**：`e^(x_i - M) = e^(x_i) / e^M`。分子分母同时乘以常数 `e^(-M)`，结果不变，因此数学上是严格等价的（排除 D）。
- **数值稳定性**：如果 `x_i = 1000`，`e^1000` 直接溢出为 inf。减去最大值 M 后，最大指数为 0（即 `e^0 = 1`），其他为负数，完美避开溢出。
- **梯度不变**：由于前向传播结果完全不变，反向传播时按链式法则求导得到的梯度也完全相同，无需任何特殊处理（排除 B）。
- **知识点来源**：深度学习（数值稳定性）。

**背景知识：**

- **指数齐次性**：$\mathrm{softmax}(x)_i = \dfrac{e^{x_i}}{\sum_j e^{x_j}} = \dfrac{e^{x_i - M}}{\sum_j e^{x_j - M}}$，对任意常数 $M$ 成立——分子分母同乘 $e^{-M}$ 约掉。取 $M = \max_j x_j$ 后输出严格不变，是纯恒等变形（排除 D）。
- **溢出阈值**：FP32 下 $e^x$ 在 $x \gtrsim 88$ 时溢出为 inf，FP16 在 $x \ge 11$ 即溢出。减最大值后最大指数为 $e^0 = 1$，其余为负指数，彻底避开上溢；极小值下溢到 0 也无害。
- **梯度不变**：前向输出逐位相同 → 链式法则算出的梯度逐位相同，无需特殊处理（排除 B）。
- **工程实践**：更稳妥的是 log-softmax——直接计算 $\log \mathrm{softmax}$ 并在内部减最大值，配合交叉熵从 logit 直接计算，避免“先 softmax 再取 log”的精度损失；这是主流深度学习框架的标准实现。

## 17. 机器学习评估（多选）

**题干：** 在机器学习模型评估中，以下哪些指标常用于衡量线性回归模型的性能？

- A. 准确率
- B. MAE
- C. MSE
- D. 决定系数 R²

**正确答案：B、C、D**

**深度解析：**

- **任务区分**：线性回归是回归任务，预测连续数值。分类任务（如逻辑回归）才使用准确率（Accuracy）。
- **回归指标**：
  - **MAE（平均绝对误差）**：预测值与真实值绝对误差的平均值，对异常值较稳健。
  - **MSE（均方误差）**：平方误差的平均值，对异常值敏感，是优化时的标准损失函数。
  - **R²（决定系数）**：衡量模型对目标变量方差的解释比例，越接近 1 拟合越好。
- **知识点来源**：机器学习（模型评估指标）。

**背景知识：**

- **回归指标一览**：

| 指标 | 定义 | 特点 |
|---|---|---|
| MAE | $\frac{1}{n}\sum \lvert y_i - \hat{y}_i \rvert$ | 误差线性累积、对异常值稳健，对应 Laplace 噪声的 MLE |
| MSE | $\frac{1}{n}\sum (y_i - \hat{y}_i)^2$ | 平方放大大误差、对异常值敏感，处处可导，对应高斯噪声 MLE |
| RMSE | $\sqrt{\mathrm{MSE}}$ | 与 $y$ 同量纲，便于解读 |
| R² | $1 - \dfrac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}$ | 解释方差比例；模型差于“永远猜均值”时可为负；Adjusted R² 补偿特征数 |

- **选项 A 陷阱**：准确率需要离散的类别判定，对连续输出无定义，属分类指标（同族：精确率、召回率、F1、AUC）。
- **命名陷阱**：逻辑回归名字带“回归”实为分类算法，损失是交叉熵而非 MSE。

## 18. 联邦学习与相关性分析（多选）

**题干：** 相关系数矩阵显示：特征 1 与特征 4 相关性 0.90，特征 2 与特征 4 相关性 0.10，特征 3 与特征 4 相关性 0.85，特征 1 与特征 3 相关性 0.88。以下分析正确的是？

- A. 特征 1 与全局提升值的相关性高于特征 3
- B. 仅保留特征 1 即可，特征 3 存在多重共线性
- C. 算力与提升值相关性极弱，说明无影响
- D. 特征 3 与特征 1 高相关，符合“样本越多，准确率越高”的数据特性

**正确答案：A、D**

**深度解析：**

- **A 正确**：0.90 > 0.85，绝对值越大相关性越强。
- **B 错误**：虽然特征 1 和特征 3 存在多重共线性（0.88），但高相关不意味着必须盲目删除。特征 3 可能包含特征 1 无法解释的独立信息。通常需用 VIF 检验或 L1 正则化来筛选。
- **C 错误**：线性相关系数弱（0.10），不代表“无影响”。可能存在非线性关系，或者该特征的影响被其他特征掩盖了。
- **D 正确**：符合联邦学习常识：客户端数据样本量越大，本地训练的模型准确率通常越高。
- **知识点来源**：联邦学习、皮尔逊相关系数。

**背景知识：**

- **Pearson 相关系数**：度量线性关联强度，取值 $[-1, 1]$，$|\rho|$ 越大线性关系越强。两大局限：只看线性——$y = x^2$ 对称分布时 $\rho = 0$ 但显然相关；受异常值影响大。非线性关联可用 Spearman 秩相关。
- **多重共线性**：特征 1、3 相关 0.88 属于共线性，后果是 OLS 系数方差膨胀、估计不稳定、符号可翻转。但对策不是无脑删除（B 错），而是：VIF 检验（>10 视为严重）、L1/L2 正则化、PCA、或依据特征重要性 / p 值判断增量信息。共线 ≠ 冗余。
- **弱相关的正确解读**：$\rho = 0.10$ 只排除线性影响（C 错），可能存在非线性关系、交互效应，或该特征的影响被其他特征掩盖（suppression 效应）。
- **联邦学习背景**：non-IID 环境下，本地样本越多本地模型训得越好，对全局提升越大（D 对应此统计规律）。

## 19. L2 正则化（多选）

**题干：** 以下关于 L2 正则化逻辑回归的说法，哪些正确？

- A. 使所有参数精确为 0
- B. λ 趋近无穷大时参数 w 趋于零向量
- C. 目标函数仍是凸函数
- D. 等价于对 w 施加零均值高斯先验（MAP）

**正确答案：B、C、D**

**深度解析：**

- **A 错误**：L2（岭回归）的惩罚项是二次函数，在 0 点处光滑可导，参数只能无限趋近于 0 但不精确为 0。精确为 0 是 L1（Lasso）的特性（0 点不可导）。
- **B 正确**：λ 极大时，正则化项主导损失，优化器必须让 w 趋于 0 才能最小化目标函数。
- **C 正确**：逻辑回归原损失是凸函数，L2 惩罚项也是凸函数，凸函数之和仍是凸函数，保证全局最优解。
- **D 正确**：贝叶斯视角下，L2 正则化等价于参数服从均值为 0、协方差为 `σ² I` 的高斯先验分布（MAP 估计）。
- **知识点来源**：机器学习（正则化、贝叶斯估计）。

**背景知识：**

- **形式**：$\min_w\ L(w) + \lambda \lVert w \rVert_2^2$（岭回归），逻辑回归中为交叉熵 + 二次惩罚。
- **L1 vs L2 对比**：

| | L1（Lasso） | L2（Ridge） |
|---|---|---|
| 惩罚项 | $\lambda \lvert w \rvert$ | $\lambda w^2$ |
| 0 点可导性 | 不可导（梯度恒为 $\pm\lambda$，常数拉力） | 光滑可导（梯度 $2\lambda w \to 0$，像缓冲垫） |
| 解的特性 | 稀疏、精确为 0、特征选择 | 缩小但永不精确为 0、稠密 |
| 几何约束 | 菱形，尖角落在坐标轴上 → 稀疏解 | 圆，光滑 → 稠密小权重 |
| 贝叶斯先验 | Laplace 先验 | 高斯先验 $\mathcal{N}(0, \sigma^2 I)$ |

- **凸性**：交叉熵损失是凸函数，二次惩罚也是凸函数，凸函数之和仍凸 → 存在唯一全局最优，梯度下降保证收敛。
- **MAP 推导**：最大化后验 $\log p(y \mid x; w) + \log p(w)$，取高斯先验则 $-\log p(w) \propto \lVert w \rVert^2$，即 L2 正则。
- **作用机理与延伸**：缩小权重 → 降低对输入扰动的敏感度 → 降方差、抗过拟合，同时改善 Hessian 病态；深度学习中的 weight decay 源于此，AdamW 是解耦实现。

## 20. Transformer 架构（多选）

**题干：** Multi-Head Attention 中，若头数增加而模型隐藏层维度 d_model 不变，会导致：

- A. W_o 参数量不变
- B. 总计算量减小
- C. 模型参数量减少
- D. 每个头的计算量减小

**正确答案：A、D**

**深度解析：**

- **维度关系**：每个头的维度 `d_k = d_model / h`。
- **A 正确**：`W^O` 的维度始终是 `d_model × d_model`，参数量不受头数 h 影响。
- **B、C 错误**：总参数量（`W^Q, W^K, W^V, W^O`）和总计算量（线性投影 + 注意力计算）在 d_model 不变时基本保持不变。
- **D 正确**：因为 `d_k` 变小，每个头内部的 `QK^T` 和 `AV` 计算复杂度降低。
- **知识点来源**：深度学习（Transformer 多头注意力机制）。

**背景知识：**

- **维度关系**：`d_k = d_model / h`。固定 `d_model`、增大头数 $h$ 时：
  - **A ✓**：$W^O$ 的维度始终是 `d_model × d_model`，与 $h$ 无关；`W^Q, W^K, W^V` 各自拼接后同样是 `d_model × d_model`，总参数量不变（C 错）。
  - **B ✗**：总 FLOPs（线性投影 + 注意力计算）在 `d_model` 不变时基本不变——计算只是重新分配而非减少。
  - **D ✓**：`d_k` 变小，每个头内 $QK^\top$、$AV$ 的计算复杂度下降。
- **代价与极限**：头太多则每个子空间太窄、单头表达力不足；极端情形 $h = d_{model}$ 时每头维度为 1，注意力退化为对单个标量打分。实践中增大 $h$ 收益递减。
- **记忆锚点**：“切得更碎，总量不变”——多头是并行细分而非压缩。对比 GQA：砍的是 KV 头的冗余（省 KV Cache），而非 Q 头子空间。

## 21. 编程题：K-Median 聚类

**题干：** K-Median 聚类，使用曼哈顿距离，输出样本标签、中心点、目标函数值（inertia），保留 6 位小数。空簇保留上一轮中心。

**详细解析（算法与避坑）：**

- **算法流程**：
  1. **初始化**：严格按照题干，取前 k 个样本作为初始中心。
  2. **分配**：计算每个样本到 k 个中心的曼哈顿距离，分配到最近的中心（距离相同时选索引小的）。
  3. **更新**：对每个簇，计算每个特征维度上的中位数作为新中心（注意：偶数个需取中间两个数的平均值）。
  4. **收敛**：计算所有中心的变化量（绝对值之和），若 `< 1e-4` 或达到 100 次迭代则停止。
  5. **空簇处理**：若某簇为空，保留原中心不变。
- **避坑指南**：
  - **输入清洗**：评测平台可能输入带有 `[1,2]` 或 `1,2` 格式，需使用 replace 清洗 `[`、`]`、`,` 字符。
  - **输出格式**：严格遵循“第一行标签 -> k 行中心 -> 最后一行 inertia”，全部保留 6 位小数。
- **知识点来源**：机器学习聚类算法、ACM 编程基础。

**参考代码：**

```python
import sys

def get_dist(a, b):
    # 曼哈顿距离
    return sum(abs(x - y) for x, y in zip(a, b))

def main():
    input_data = sys.stdin.read().split()
    if not input_data: return
    n, d, k = map(int, input_data[:3])

    pts = []
    idx = 3
    for _ in range(n):
        pt = list(map(float, input_data[idx:idx+d]))
        pts.append(pt)
        idx += d

    # 初始化：取前k个作为中心
    centers = [pts[i][:] for i in range(k)]
    labels = [0] * n

    for _ in range(100):
        groups = [[] for _ in range(k)]
        # 分配
        for i in range(n):
            best_c = 0
            min_dist = float('inf')
            for c in range(k):
                dist_val = get_dist(pts[i], centers[c])
                if dist_val < min_dist:
                    min_dist = dist_val
                    best_c = c
            labels[i] = best_c
            groups[best_c].append(pts[i])

        # 更新
        new_centers = []
        shift = 0.0
        for c in range(k):
            if not groups[c]:
                new_centers.append(centers[c])
                continue

            new_c = []
            for dim in range(d):
                vals = sorted([p[dim] for p in groups[c]])
                m = len(vals)
                if m % 2 == 1:
                    new_c.append(vals[m // 2])
                else:
                    new_c.append((vals[m // 2 - 1] + vals[m // 2]) / 2.0)
            new_centers.append(new_c)
            for dim in range(d):
                shift += abs(new_c[dim] - centers[c][dim])

        centers = new_centers
        if shift < 1e-4:
            break

    # 计算 inertia
    inertia = sum(get_dist(pts[i], centers[labels[i]]) for i in range(n))

    # 输出
    print(' '.join(map(str, labels)))
    for c in centers:
        print(' '.join(f'{x:.6f}' for x in c))
    print(f'{inertia:.6f}')

if __name__ == '__main__':
    main()
```

## 22. 编程题：分组查询注意力（GQA）

**题干：** 实现 GQA，将 Q 分为 num_q_heads，KV 分为 num_kv_heads，Q 头分组共享 KV，实现缩放点积注意力并拼接。

**详细解析（算法与避坑）：**

- **核心逻辑**：
  1. GQA 是 MHA 和 MQA 的折中。分组数 `g = num_q_heads / num_kv_heads`。
  2. 外层循环遍历 KV 头（num_kv_heads），内层循环该组内的 Q 头（g 个）。
  3. 对每个 Q 头：提取对应的 Q, K, V 矩阵；计算 `QK^T / √(d_k)`；加上 Mask；做 Softmax（先减最大值防溢出）；乘 V 得到输出。
  4. 将输出按 Q 头顺序拼接。
- **避坑指南**：
  - **维度对齐**：注意 `d_k` 和 `d_v` 可能不同，拼接时需按 `d_v` 的维度拼接。
  - **Mask 处理**：通常 Mask 矩阵中 0 表示屏蔽（设为 `-1e9`），1 表示保留。
  - **数值稳定**：Softmax 必须减去该行的最大值，防止 exp 溢出。
- **知识点来源**：大模型推理加速（GQA）、ACM 编程。
